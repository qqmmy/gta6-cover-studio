An offline cover-art studio that turns one or more of your own photos and a caption into a multi-panel, Vice-City-grade poster and exports it as a PNG in 1080x1080, 1080x1350 or 1920x1080. Everything runs in the browser on Canvas: no network request, no upload, no build step.

## Run it

```sh
node serve.ts
```
